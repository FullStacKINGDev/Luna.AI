1 · Overview

Luna.AI ("we", "our", "the bot") is a Discord bot created by Fullstackingdev. This Privacy Policy explains what data Luna.AI collects, why it collects it, and how it is handled. We are committed to protecting your privacy and minimizing data collection to only what is essential.

By using Luna.AI, you agree to the practices described in this policy.

2 · Data We Collect

Luna.AI collects only the minimum data required to function. Here is an exact breakdown:

Data Type What Is Stored Why Stored?
Server (Guild) ID The numeric ID of your Discord server To tie a reaction role message to the server it belongs to Yes (reaction_roles.json)
Message IDs ID of reaction role panel messages To identify which message to listen for reactions on Yes (reaction_roles.json)
Channel IDs ID of the channel where reaction role panel was posted For reference in reaction role configuration Yes (reaction_roles.json)
Role IDs The ID of each role mapped to a reaction emoji To assign the correct role when a user reacts Yes (reaction_roles.json)
/customize requests The description an administrator types, and a snapshot of the server's structure: the names, types, colours and short topics (first 80 characters) of its roles, categories and channels, and whether each channel is private To let the AI plan a change that fits the existing server Not stored by Luna.AI. Sent to OpenAI's API (see section 6)
Structure backups Before editing or deleting, the server's roles, channels and permission settings (IDs, names, topics, permission values). Where a channel has permissions set for an individual member, that member's ID is included. No messages are stored. So an administrator can rebuild after an edit or a deletion Yes (backups/ folder on the host)

All stored data is saved locally on the bot host machine in a JSON file (reaction_roles.json). No external database or cloud service is used.

3 · Data We Do NOT Collect

Luna.AI explicitly does not collect or store:

  • ❌ Message content or chat logs
  • ❌ User IDs or personal Discord profile information
  • ❌ Usernames, discriminators, or avatars
  • ❌ IP addresses
  • ❌ Email addresses
  • ❌ Voice channel activity
  • ❌ DMs or private messages
  • ❌ Any Personally Identifiable Information (PII)

4 · How Data Is Used

The limited data Luna.AI stores is used exclusively for:

  • Reaction Role Functionality: Matching a Discord reaction event to the correct role assignment, using the stored message ID and emoji-to-role mapping.
  • Server Customization: When an administrator runs /customize, their description and a snapshot of the server's structure are used once to plan the change. The plan is kept in memory only while the administrator reviews it, and is discarded afterwards. Luna.AI does not keep a copy of the plan or of the AI's response.
  • Backups: Before carrying out a plan that edits or deletes anything, Luna.AI writes the server's structure to a JSON file on the host so the administrator has a record to rebuild from. It is used for nothing else.

Data is never used for advertising, profiling, analytics, or any purpose beyond the core bot features.

5 · Data Storage & Security

  • Location: All data is stored locally on the machine running the bot (the server administrator's host).
  • Format: A plain JSON file (reaction_roles.json) in the bot directory, and one JSON file per backup in the backups folder.
  • Security: Access is limited to whoever has access to the host machine. The bot token and the OpenAI API key are stored in a .env file and should never be shared.
  • No Cloud Storage: We do not use any remote databases, cloud services, or third-party storage providers.

6 · Third-Party Sharing

Luna.AI does not sell or share data with advertisers or data brokers. It communicates with two external services:

  • Discord API, to read events and send responses, governed by Discord's own Privacy Policy.
  • OpenAI API, used only when an administrator runs /customize. Luna.AI sends the administrator's typed description and a snapshot of the server's structure: the names, types, colours and short topics (first 80 characters) of its roles, categories and channels, and whether each channel is private, so the AI can plan the change. It does not send message content, member lists, usernames or user IDs. OpenAI processes this data under its own Privacy Policy. Please don't put personal information in your /customize request.

We do not sell, rent, trade, or license any data to anyone.

7 · Data Retention

Data stored by Luna.AI (reaction role configuration and structure backups) is retained as long as the files exist on the host machine. Backups are never deleted automatically.

  • Removing the bot from your server does not automatically delete the stored configuration file.
  • The server administrator can manually delete reaction_roles.json and the backups folder at any time to remove all stored data.
  • You may also contact us to request deletion (see below).

8 · Data Deletion Requests

You have the right to request deletion of any data associated with your server. To do so:

  1. Remove Luna.AI from your Discord server.
  2. Contact us via GitHub (see below) with your Server ID and a deletion request.
  3. We will confirm and purge all associated data within 7 business days.

Alternatively, if you are self-hosting the bot, simply delete the reaction_roles.json file and the backups folder from your host machine.

9 · Children's Privacy

Luna.AI is not directed at children under the age of 13. We do not knowingly collect any information from children. Discord itself requires users to be at least 13 years old. If you believe a child has interacted with the bot in a way that raises privacy concerns, please contact us immediately.
