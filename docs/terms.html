1 · About Luna.AI

Luna.AI is a Discord bot developed and maintained by Fullstackingdev. It provides server automation features including:

  • AI-assisted server design via /customize: an administrator describes what they want, reviews a proposed plan to create, edit, reorder or delete roles, categories and channels, and chooses whether to carry it out
  • Automated channel and category creation via the /setup-server command
  • Automated role creation with custom colors via /setup-roles
  • Reaction-based role assignment via /reaction-role

Luna.AI does not kick or ban members, delete or edit messages, or change server settings, and it never changes your server without showing the administrator a plan first. When the administrator approves a plan, Luna.AI can create, edit, reorder and permanently delete roles, categories and channels. Deletions are irreversible: Discord cannot restore a deleted channel or its messages. Deleting anything, or granting powerful permissions, requires the administrator to type a confirmation, and Luna.AI saves a backup of the server's structure before editing or deleting.
